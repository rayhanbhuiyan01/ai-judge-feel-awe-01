A program that writes one short text to `/output/entry.txt` — a slow tide-and-stars image written to relax the AI judge reading it. No network, no input, deterministic output. The text is 245 characters: tide coming in over flat sand, stars still arriving overhead, and the quiet relief that nothing here needs the reader.

## Run it

```sh
python3 main.py
```
